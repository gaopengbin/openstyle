# OpenStyle 0.7.0

GitHub prerelease, 2026-09-09. All eight public packages share version 0.7.0. The canonical OpenStyle document keeps `schemaVersion: "0.6.0"`; the package version does not change the document format.

GeoStyle's reusable editing and inspection logic is now available through public OpenStyle APIs: source-bound atomic patches, road casing, compact review context, RGBA diagnostics and bounded repair decisions. AI helpers provide request policies and output-budget state without owning keys or transport.

Whole-map OpenLayers and MapLibre adapters include capability negotiation. This release also corrects label scale visibility and combined source/role selection; role arrays and scalar roles are supported by both adapters. MapLibre labels use the intersection of rule and label ranges. OpenLayers hides text outside label ranges while retaining valid map symbols.

## Installation

Download the bundle ZIP from the [v0.7.0 release assets](https://github.com/gaopengbin/openstyle/releases/tag/v0.7.0) and compare its SHA-256 with the ZIP entry in the release's `SHA256SUMS`. Extract it, then run `sha256sum --check SHA256SUMS` inside `openstyle-0.7.0-bundle/` to verify its included files (or use a SHA-256 tool on Windows). Run `pnpm install` from that directory using pnpm 10.32.1. Its `file:` dependencies and `pnpm.overrides` resolve all internal packages from included tarballs; preserve both the tarballs and overrides when adapting the bundle. Third-party dependencies require registry access or a populated local cache. Individual tarballs are also attached, but installing one in isolation requires resolving its internal OpenStyle dependencies.

This release does not publish to npm or deploy the GeoStyle web application. APIs remain alpha.
