# Claude Code skills

Reserved for [Claude Code](https://claude.com/claude-code) skills that expose openstyle to AI workflows.

## Planned

- **`sld-generator`** — end-to-end: understand a user's styling request, call `@openstyle/ai`, validate with `@openstyle/schema`, compile with `@openstyle/compiler`.
- **`sld-review`** — read an existing SLD, surface structural issues, suggest edits.
- **`sld-cookbook`** — quick reference lookup into GeoServer's SLD cookbook, palettes, and scale ladders.

## Installing (once implemented)

Skills in this directory can be linked into a project by copying them under `.claude/skills/`. See the [Claude Code skills docs](https://docs.claude.com/en/docs/claude-code/skills) for the schema.

Contributions welcome.
